# Security notes\n\n## Threat model\n\n`schema-inference` is a pure Python library designed without I/O side effects.\n\n### Defended\n\n- **Unbounded recursion**: The library implements `max_depth` (default 32) to prevent stack overflow on deeply nested JSON structures.\n- **Memory exhaustion**: The library implements `max_records` (default 100,000) and `max_properties` (default 1,000) to bound resource usage.\n- **Data leakage**: No network calls are made. No secrets are stored.\n\n### Not defended\n\n- **Hostile Inputs**: While it uses robust parsing, it is the caller's responsibility to sanitize inputs before passing them to the inference functions if the input source is untrusted.\n\nFor vulnerability reporting, see the repository security policy.
